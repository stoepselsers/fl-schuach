# FL Schuach

Pattern-Sequencer im Browser: Channel Rack, Piano Roll, Playlist und Mixer mit eigenen Drum- und Synth-Klängen.

Die App ist passwortgeschützt. Diese Seite enthält nur eine verschlüsselte Version (AES-256), die erst mit dem richtigen Passwort im Browser entschlüsselt wird.

**Öffnen:** https://stoepselsers.github.io/fl-schuach/
